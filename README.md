# SWYNEX – Exploratory Data Analysis

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a Students Performance dataset containing 1,000 records and 8 original columns.

## Objectives
- Understand the dataset structure.
- Identify missing values and duplicate records.
- Calculate descriptive statistics.
- Analyze student performance patterns.
- Identify correlations and outliers.
- Generate meaningful insights using visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Dataset overview
2. Descriptive statistical analysis
3. Gender-wise performance analysis
4. Parental education analysis
5. Lunch type analysis
6. Test preparation analysis
7. Score distribution
8. Correlation heatmap
9. Outlier detection
10. Overall student performance

## Project Files
- `cleaned_students_performance.csv` – Cleaned dataset.
- `exploratory_data_analysis.ipynb` – Complete EDA notebook.
- `student_performance_eda_results.csv` – Analysis results.

## Conclusion
The project demonstrates how Python can be used to explore datasets, identify patterns, visualize relationships and extract useful insights from student performance data.
